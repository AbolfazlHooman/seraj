# سراج | SERAJ

اپ وب (فایل `www/index.html`) که با Capacitor به APK اندروید تبدیل می‌شود.

## گرفتن APK
1. پروژه را در یک مخزن GitHub بگذارید (شاخهٔ `main`).
2. به تب **Actions** بروید؛ workflow با نام **Build APK** خودکار اجرا می‌شود
   (یا از **Run workflow** دستی اجرایش کنید).
3. بعد از پایان (حدود ۴ تا ۷ دقیقه) در پایین صفحهٔ اجرا، بخش **Artifacts** فایل `seraj-apk` را دانلود کنید.
4. فایل zip را باز کنید و `app-debug.apk` را روی گوشی نصب کنید.

## به‌روزرسانی اپ
فایل `www/index.html` را عوض و commit کنید؛ APK جدید خودکار ساخته می‌شود.
